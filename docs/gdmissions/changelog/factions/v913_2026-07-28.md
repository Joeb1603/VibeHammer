# Faction Changelog: data version 913 (2026-07-28)

Source: https://gdmissions.app/11th/rules/faction-changelog

Faction changes across 5 factions.

## Adeptus Astartes

### Bladeguard Veteran Squad

- Bladeguard Veteran Squad: updated "Bladeguard" ability
  - Before: At the start of the Fight phase, you can select one of the following abilities to apply to models in this unit until the end of the phase: ■ Swords of the Chapter: Each time a model in this unit makes a melee attack, re-roll a Hit roll of 1. ■ Shields of the Chapter: Each time an invulnerable saving throw is made for a model in this unit, re-roll a saving throw of 1.
  - After: (Once per turn, per unit): In the Fight phase, when this unit is selected to fight or when an enemy unit targets this unit, you can select one of the following: ▪ This unit’s melee attacks have +1 to hit rolls. ▪ Or: Attacks that target this unit have -1 to hit rolls.
