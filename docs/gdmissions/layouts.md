# Terrain Layouts

Source: https://gdmissions.app/11th/layouts

Three recommended layouts for each force disposition matchup (15 matchups, 45 layouts; a matchup and its reverse share the same layouts). The site publishes these only as images. The versions with measurements are stored in `layouts/`; the same images without measurements are on the site at `https://gdmissions.app/assets/11th/layouts/no-measurements/<same file name>`.

Legend (from the images): 60" x 44" board, Attacker at the top edge (red zone), Defender at the bottom edge (blue zone); Home, Centre and Expansion objectives; baseplates (terrain areas), ruin walls and obstacles. Measurements are in inches from the battlefield edges.
