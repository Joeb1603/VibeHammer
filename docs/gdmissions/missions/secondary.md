# Secondary Missions

Source: https://gdmissions.app/11th/secondary-missions

The 18 secondary mission cards. The site publishes an Attacker and a Defender card image for each; the text below is the site's card text (served for the Defender deck). The Attacker card images carry the same rules in a different colour (checked for Cleanse only).

Flags column: `or` = alternative to the row above, `cumulative`/`plus` = adds to the rows above, `fixed` = the row used when the card is a Fixed mission, `wm` = as flagged on the site (unlabelled there). ==text== marks a highlighted term.

## Cleanse

Tactical · [card page](https://gdmissions.app/11th/secondary-missions/cleanse-defender)

**WHEN DRAWN:** If the Plunder **Secondary Mission** is active for you, <u>you can</u> draw one new **Secondary Mission** card and shuffle this card back into your **Secondary Mission** deck.

### Action: CLEANSE

| | |
|---|---|
| **STARTS** | Your Shooting phase. |
| **UNITS** | One friendly unit within range of one **objective** (excluding your **home objective**). |
| **USE LIMIT** | Unlimited. Each unit that starts this **action** this phase must be within range of a different **objective**. |
| **COMPLETES** | End of your turn, if that unit is controlling that **objective**. |
| **EFFECT** | That **objective** is ==cleansed== by your army. |

### ANY BATTLE ROUND

**When:** End of your turn

| Condition | VP | Flags |
|---|---|---|
| One **objective** was ==cleansed== by your army this turn. | 2 |  |
| Two or more **objectives** were ==cleansed== by your army this turn. | 5 | or |
