# gdmissions.app: Warhammer 40,000 11th Edition reference

Scraped from https://gdmissions.app/11th (site title "GDM 2026", app data version 995) on 2026-11-20. English only; the site also serves the Core Rules in seven other languages.

**Copyright:** this is Games Workshop rules text as republished by a third-party site. Like `docs/rules/` and `docs/datasheets/`, it may live in this private repo only: never copy it into `data/`, the package, a release or anywhere public.

**Status as a rules source:** `docs/rules/` (the PDF extraction) stays the engine's source of truth. This folder is a third-party, "simplified" transcription. Its value is the 101 *APP* entries (rules that exist only in the Warhammer 40,000 app, e.g. Modifying Dice Rolls, Re-rolls, Closest Model/Unit) next to the 186 *PDF* entries, plus the mission pack. It is not verified against the app; check it against the decisions in `docs/decisions.md` before relying on it.

Not included: the Game Tracker (an interactive score tracker with no rules content), the site's version history, the card images (their text is transcribed here) and the 10th edition pages.
