## D-085: One bot: the levels Easy and Hard and the hidden regression levels removed; Easy's answers kept as the bot's defaults (M85; amends D-054, supersedes the level parts of D-066, D-067, D-078, D-080 and D-083)
**Decided:** 2026-11-11 (agreed with the user while planning M85–M87, PLAN.md "One bot, objectives, and the bot playing
for them"; the arena flags and `--bot-level` agreed in M85's plan). Bot, client and arena only: no rule, core, state,
action, event or replay-format change.

Three levels plus the hidden copies (`easy-m55`, `normal-m55`, `normal-m77`, `hard-m77`) made every bot change
expensive: each had to be kept, measured and proved unchanged. With objectives coming (D-084, M86–M87) one bot gets the
work instead.

- **What is kept.** Level Normal, exactly as it played at the end of the Teamwork batch (D-083). Its play is unchanged:
  the Release arena's `--per-game` lines (actions, final state and decision-trace hashes) are identical before and
  after on V1, both bot scenarios, Strike, the rosters, random armies (auto and hand deployment) and the M73 lists, 200
  games each (M85 Results).
- **Recoverable.** The commit before M85 is tagged `bots-three-levels` (pushed): Easy (`baseline_bot`), Hard
  (`src/ai/hard/`), `generation.hpp` and their tests and replays are there.
- **Removed.** Level Hard (`src/ai/hard/`: the evaluator, the lookahead, the chain cache, `BotWeights`); level Easy as a
  level; `src/ai/generation.hpp` (`Generation`, `pre_teamwork`, `hard_generation`) and every M55 / pre-teamwork
  branch (the Current branch kept in each); `BotLevel` (client and ai), `effective_level`, `chain_tables_built`,
  `share_chain_cache`, `uses_deploy_heuristic`; code only Hard called (`normal::furthest_standing_move`, the shooting's
  given army plan, `AttackOutcome::wounds_left_pmf`, the log's "(Hard: ...)" parsing and its win / draw / loss odds).
- **Easy's answers become the bot's defaults.** Normal never answered every decision itself: whatever it had no answer
  for went to Easy's policy (wound re-rolls, a move that stands when no planned one does, charge targets and moves when
  its own plan fails, the editors' defaults). That code moves, unchanged and with its reasons word for word, to
  `src/ai/normal/defaults.*` (`normal::default_answer`); the M55 branches go. M74's deployment policy (`deploy_policy`)
  stays as the heuristic's answer when it has none, and the fallback's.
- **`normal::no_plan`.** The army plan's no-op answer (every unit its closest enemy unit, no partners, inactive) is
  exposed: it is what the pre-batch generation read, so tests compare a unit's play with and without partners through
  it.
- **`BotConfig`** holds only the move score's weights (`normal::MoveWeights`, the shipped defaults unless the arena
  overrides them).
- **Arena.** `--a` / `--b` and the level names are gone (an unknown flag exits 2). `--weights key=value,...` sets the
  move weights for both sides, `--weights-a` / `--weights-b` for one side (applied in the order given): `delay`,
  `survival`, `edge`, `coherency`, `approach`, `cohesion`, `follow`, `approach_alone`; any other key exits 2. The
  header line names the weights each side plays with ("default" when none are given).
- **Client.** The start screen and the army builder lose the level choice; the status and watch bar no longer name a
  level. A settings file or a save that names a level (`"bot_level"`, in the settings or in a save's `"players"` block)
  loads and ignores it, and saving drops it. `--bot-level` is gone; like any unknown flag the client ignores it.
- **Tests.** A test of removed code is deleted; one that also checked kept code keeps those checks. Easy's single
  decisions are checked as the defaults' (`tests/ai/default_choice.hpp`); games Easy or Hard played are played by the bot
  on the same seeds. Positions only the pre-batch bots reached are kept as state fixtures (`tests/data/states/`). The
  replays m45, m47, m58, m70 and m75 (Easy or Hard games) are deleted; Normal's m46, m68, m73 and m77 are unchanged.
  The full list of deleted tests is in M85's Results.
